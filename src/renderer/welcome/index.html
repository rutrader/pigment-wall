Pigment

A day is a picture. It colours in as you burn tokens.
Reads
Your Claude Code session logs in ~/.claude/projects — the timestamp and token counts of each response, and nothing else.
Never reads
The content of your conversations, file paths, project names or branch names. They are in those files; Pigment does not take them.
Never sends
Anything, anywhere. There is no network code in this app.
Lives in
The menu bar. The icon fills as the day goes on; click it for today's picture and the wall behind it.
Settings and the day boundary are in the tray menu.
